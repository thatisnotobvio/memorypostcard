✉️ Postcard Vibe – Digital Postcard Generator

A moody, visual storytelling tool that lets users create and share digital postcards inspired by real-world places. Designed for slow communication, nostalgia, and quiet aesthetics.

🎯 Features
- 📸 **Curated Visuals** – Postcards come alive with cinematic photography and subtle overlays
- ✏️ **Personalized Messages** – Customize the note, location, and tagline
- 🔗 **Shareable Links** – Generate a unique, copyable URL for each postcard
- 📥 **Download as Image** – Save your postcard locally as a high-quality PNG
- 🌍 **Paris Prequel** – First edition features the golden light of Paris

🧠 Built With
- React + Vite
- HTML Canvas (for image rendering)
- Tailwind CSS (or styled components)
- UUID-based routing
